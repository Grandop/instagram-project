## Mapa de mecanismos (frequencia)

| Mecanismo | Frequencia | Exemplo literal |
|-----------|------------|-----------------|
| Lacuna / pergunta-resposta | Alta | “Como eu faço…?” → resposta imediata; “sabe qual que é o novo luxo?” |
| Lista / passos | Alta | Arquivar stories; 9 posts; tema + gancho + objetivo |
| Pattern interrupt / bronca | Media | “vocês não aplicam”; “problemas no Instagram” |
| Re-gancho identidade | Media | “Eu te falei que você ia gostar de mim” (volta no fim) |
| Cliffhanger humor | Baixa/media | “Se durou ou não, fica no imaginário de vocês” |
| CTA plataforma | Alta | “curtir esse vídeo pra plataforma distribuir” |
| CTA comportamento | Media | “Jura de dedinho que vai gravar o vídeo hoje?” |
| Loop / callback | Media | Abre “vai gostar de mim” e fecha com a mesma frase |

## Arco tipico de retencao deste criador
1. Gancho (dor/tabu/pergunta)
2. Tese em 1–2 frases
3. Explicacao pratica (como eu faco / por que funciona)
4. Consequencia (venda, autoridade, seguranca no relacionamento)
5. CTA curto (curtir / gravar / aplicar)

## Trechos fortes
- “mas não passe esse vídeo não, você vai gostar de mim” → anti-saida + promessa social
- “Stories é para poder ver no mesmo dia. Não viu, acabou.” → corte seco, ritmo
- “Me ajuda a durar. Se durou ou não, fica no imaginário” → cliffhanger sexual/humor cristão
- “bora ver as visualizações caindo. Jura de dedinho…” → CTA lúdico
- “Eu te falei que você ia gostar de mim, não esquece de curtir…” → callback + engajamento

## Pontos fracos recorrentes
- Videos muito curtos de tip unico (#1) — pouco “meio”; retencao = so densidade
- #2 invalido — nao da pra inferir retencao

## Como replicar
1. Prometa resultado nos 3s; entregue micro-payoff em 10s
2. Use “eu faco assim” + 2–3 passos
3. Bronca leve no meio (“voce nao aplica”)
4. Feche com CTA de plataforma OU compromisso comportamental
5. Se abriu com frase-assinatura, **repita no fim** (loop)
6. Em historia: corte antes do detalhe intimo (“fica no imaginario”)
7. Nomeie o inimigo operacional (“problemas”, “falso rico”, “passatempo”)
8. Segure com especificidade (9 posts, arquivo diario, Rolex falso)
