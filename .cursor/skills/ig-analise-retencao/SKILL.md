# IG Analise — Retencao

## Antes de tudo

1. Leia `.cursor/skills/ig-contexto/SKILL.md`.
2. Monte o corpus (texto colado **ou** pasta de `.txt` — junte com `=== FILE: ... ===`).
3. Busque **padroes recorrentes** de como o criador segura atencao.

## Escopo

Do pos-gancho ate o fechamento. Mapeie mecanismos de retencao ao longo do texto, nao so o inicio.

## Mecanismos a procurar

| Mecanismo | O que e |
|-----------|---------|
| Pattern interrupt | Mudanca brusca de ritmo/assunto/tom |
| Lacuna de curiosidade | Abre pergunta e atrasa resposta |
| Cliffhanger | Corta antes do payoff |
| Re-gancho no meio | Novo hook la pelo meio |
| Mudanca de ritmo | Acelera/desacelera; lista vs historia |
| Gatilho de engajamento | “Comenta”, “salva”, desafio, discordancia |
| Loop | Final que encaixa no inicio / convida rewatch |
| CTA de fechamento | Pedido claro no fim |

## Output (obrigatorio)

```markdown
# Analise de retencao — [criador ou pasta]

## Corpus
- N arquivos

## Mapa de mecanismos (frequencia)
Tabela: mecanismo | quao frequente | exemplo literal

## Arco tipico de retencao deste criador
Passo a passo do “jeito dele segurar” (inicio → meio → fim)

## Trechos fortes
3–6 citacoes com explicacao de por que seguram

## Pontos fracos recorrentes
Onde a retencao costuma cair (se houver evidencias)

## Como replicar
Checklist pratico de retencao no estilo dele (5–8 itens)
```

## Regras

- Cite falas reais do corpus.
- Regua = Instagram (`ig-contexto`), nao texto formal.
- Independente das outras analises.
- Foco em padrao do criador no conjunto, nao review video-a-video longo (a menos que peçam).
