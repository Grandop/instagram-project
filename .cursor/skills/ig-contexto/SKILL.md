# IG Contexto — lente Instagram/Reels

Skill de **contexto**, nao de analise. Nao classifica transcricoes. Serve de
regua: toda skill `ig-analise-*` le este arquivo **antes** de analisar.

## Como o Reels funciona (regua certa)

Julgue fala de criador pela logica do feed mobile, nao por texto formal/academia.

1. **Scroll is the enemy** — usuario passa em <1–2s. Se o gancho falha, o resto nao existe.
2. **Retencao > likes iniciais** — algoritmo privilegia quem assiste ate o fim / rewatch.
3. **Tom casual/lo-fi** — conversa de amigo > palestra. Imperfeicao verbal e feature.
4. **Som + legenda** — muita gente assiste sem audio; ritmo de fala deve caber em caption.
5. **Gatilho de comentario** — pergunta, discordancia, “comenta X”, escolha binaria.
6. **Save/share** — listas, frameworks, frases citaveis pedem “salva”.
7. **Loop** — final que reconecta no inicio aumenta rewatch.
8. **Cultura BR** — gíria, meme, referência TV/funk/futebol/internet BR, tratamento “voce/voce”.

## Gramatica de viralizacao (checklist mental)

| Momento | Funcao |
|---------|--------|
| 0–3s | Gancho: quem/dor/promessa/choque/curiosidade |
| 3–15s | Entrega a primeira prova ou vira a chave |
| Meio | Pattern interrupt, cliffhanger, re-gancho |
| Final | Payoff + CTA (comenta/salva/segue) e/ou loop |

## O que NAO fazer ao usar esta lente

- Nao cobrar introducao formal, tese academica, “bom dia seguidores”.
- Nao penalizar frase curta, repeticao, bordao, palavrao estrategico.
- Nao analisar “qualidade literaria” — analisar **parada de scroll + retencao + engajamento**.
