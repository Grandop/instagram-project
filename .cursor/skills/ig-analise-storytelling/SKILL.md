# IG Analise — Storytelling

## Antes de tudo

1. Leia `.cursor/skills/ig-contexto/SKILL.md`.
2. Monte o corpus (texto colado **ou** pasta de `.txt` unidos com `=== FILE: ... ===`).
3. Extraia **padroes narrativos** do criador no conjunto.

## Dimensoes

| Dimensao | Pergunta |
|----------|----------|
| Arco | Tem setup → conflito → virada → payoff? |
| Personagens | “Eu”, cliente, antagonista (ex.: “mercado”, “ex”)? |
| Concreto vs abstrato | Cenas/numeros vs teoria? |
| Loops abertos | Promete algo e fecha depois? |
| Estrutura | Lista numerada, jornada, antes/depois, tese+prova? |
| Batidas emocionais | Raiva, alivio, humor, urgencia, pertencimento? |

## Output (obrigatorio)

```markdown
# Analise de storytelling — [criador ou pasta]

## Corpus
- N arquivos

## Estruturas que ele mais usa
Rankeie (ex.: 1. antes/depois 2. lista 3. episodio com personagem)

## Arco prototipico
Descreva o “roteiro medio” deste criador em 4–7 batidas

## Personagens e exemplos concretos
Quem aparece + 3–5 exemplos literais do corpus

## Loops e payoffs
Como ele abre e fecha promessas

## Emocao dominante
2–4 batidas emocionais recorrentes com citacoes

## Como replicar
Template de roteiro no estilo dele (preenchivel) + 3 ideias de episodio
```

## Regras

- Exemplos literais — sem inventar.
- Julgue narrativa pelo que funciona em Reels (curto, concreto, payoff cedo).
- Independente; nao exige ter rodado ganchos/retencao.
- Pratico para quem vai gravar conteudo similar.
